📖 QA Automation Selector Reference Guide

Selenium / Playwright / Cypress

Every element across all 30+ QA Playground practice views contains unique id, data-testid, and data-qa attributes. Below are quick locator snippets for popular testing frameworks.

🐍 Selenium WebDriver (Python / Java)

# Python Selenium Example
from selenium.webdriver.common.by import By

username_input = driver.find_element(By.ID, "input-username")
login_button = driver.find_element(By.CSS_SELECTOR, "[data-testid='btn-login-submit']")
table_row = driver.find_element(By.XPATH, "//tr[@id='tr-user-row-1']")

username_input.send_keys("admin")
login_button.click()

🎭 Playwright (Python & Node.js)

# Playwright Python Example
page.goto("http://localhost:8000/login/")

# Locating by test-id or id
await page.locator('#input-username').fill('admin')
await page.get_by_test_id('btn-login-submit').click()

# Open Shadow DOM element access
await page.locator('#shadow-input-open').fill('Shadow DOM Input')

🌲 Cypress.io

// Cypress Test Script
describe('QA Playground - Login Test', () => {
  it('should sign in with admin credentials', () => {
    cy.visit('http://localhost:8000/login/');
    cy.get('#input-username').type('admin');
    cy.get('#input-password').type('admin123');
    cy.get('[data-testid="btn-login-submit"]').click();
  });
});
